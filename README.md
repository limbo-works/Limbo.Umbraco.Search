## Installation

### Umbraco 13

Version 13 of this package supports Umbraco version 13. The package is only available via [**NuGet**](https://www.nuget.org/packages/Limbo.Umbraco.Search). To install the package, you can use either the .NET CLI:

```
dotnet add package Limbo.Umbraco.Search --version 13.0.0
```

or the NuGet Package Manager:
```
Install-Package Limbo.Umbraco.Search -Version 13.0.0
```
